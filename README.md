# Qurbani Əmrahov — Portfolio

Personal portfolio website built with Laravel, Blade, CSS, and JavaScript.

## Features

- Responsive design
- Dark and light themes
- About, experience, technology stack, and contact sections
- Accessible navigation and mobile menu

## Preview

```bash
git clone https://github.com/qurbaniemrahov/Portfolio.git
cd Portfolio
php -S 127.0.0.1:8000
```

Open `http://127.0.0.1:8000/preview.html` in your browser.

## Laravel integration

Copy these files into an existing Laravel application:

- `resources/views/portfolio.blade.php`
- `public/assets`
- `routes/web.php`

Then start the Laravel development server with `php artisan serve`.

## Main files

- `routes/web.php` — application routes
- `resources/views/portfolio.blade.php` — portfolio page
- `public/assets/css/app.css` — page styles
- `public/assets/js/app.js` — interactive behavior
- `preview.html` — standalone local preview
